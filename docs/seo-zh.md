为什么选择快粘助手？

1. 100% 纯本地运行，隐私绝对安全
不同于其他云端工具，快粘助手坚守隐私底线。所有卡片数据、常用语均保存在您浏览器的本地存储（chrome.storage.local）中，不设云端服务器，不联网上传任何剪贴板内容，真正做到 100% 数据私密，企业级安全合规。

2. 强大的卡片与标签管理
支持卡片自定义分类、快捷置顶（Pinned）、分类标签。支持一键导出 JSON 数据备份，随时随地无缝迁移。

3. 系统级右键划词收藏
在任何网页上看到高频使用的文本、话术，只需鼠标划词，右键选择"收藏到 QuickPaste"，即可瞬间同步至侧边栏，无需手动新建。

4. 极简交互，快捷键一键呼出
支持快捷键 Alt+V 填充上次内容、Alt+C 保存选中文字为卡片，完美融入您的日常办公流，清爽无打扰。

5. 多语言支持
支持中文、英文、日文、韩文、德语、法语，满足全球用户需求。
